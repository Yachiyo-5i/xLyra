# 使用 Agent 工作台（/agent）

Runner 配置好之后，左侧导航里会出现 Agent 入口，进入 `/agent` 开始对话。没配置 Runner 时入口不显示。

## 开始对话

- 点左侧「新建对话」，输入想做的事，`Enter` 发送，`Shift+Enter` 换行。
- 输入框可以选模型。可选的模型受 [站点与模型范围](./settings.md#站点与模型范围) 限制。下次进入时会默认用你上次用过的模型。
- 对话过程里会实时显示 Agent 在做什么，比如读了几个文件、跑了几条命令、搜索了几次，做完后折叠成「已完成 N 步工作」，点开可以看细节。
- 想中途停下，点停止，状态会变成「已停止」。
- 左侧列表是历史对话，可以删除。所有对话保存在 Runner 的数据目录里。
- 修改自己发过的最后一条消息后可以重新生成，这会覆盖原来的回复。

## 权限模式

输入框旁边可以切换：

| 模式 | 行为 |
| --- | --- |
| 询问（默认） | 做关键操作之前会弹出权限请求，由你选「允许」或「拒绝」 |
| 完全访问 | Agent 直接执行，不再询问。切换时会弹出风险确认，确认后才开启 |

「完全访问」下 Agent 可以不经确认地读写文件、运行命令、访问网络，只在你信任当前任务时使用，用完建议切回「询问」。

当 Agent 想访问工作区之外的路径时，也会通过权限请求让你决定。

## 附件

发送消息时可以带附件：

- 最多 4 个文件
- 每个不超过 5 MB
- 合计不超过 20 MB

超出时会提示出错，请分开发送或压缩后再发。

## 上下文压缩

对话越长占用的模型上下文越多。占用达到设定比例时，Agent 会自动把早期内容压成摘要继续工作，界面显示「已压缩上下文」。也可以在输入框发送 `/compact` 手动压缩，需要先进入一个已有的对话。

## 右上角「配置」

在 `/agent` 页面点「配置」打开 Agent 设置，修改后在下一轮对话生效，无需重启。

| 标签 | 能做什么 |
| --- | --- |
| Skills | 管理 Agent 的技能。可以整体开关，也可以逐个添加、编辑、删除。每个 Skill 有名称（仅限小写字母、数字、中划线）、描述和操作说明正文，模型根据描述判断什么时候用它。Agent 自己创建的和外部导入的会分别标注来源 |
| 外观 | 换主页背景（可上传自己的图片，单张不超过 8 MB，最多保存 20 张），调整侧栏透明度、明暗、厚度，以及背景的模糊度和暗度，可一键恢复默认 |
| 上下文 | 设置上下文窗口大小（token，留空为 200000）和自动压缩的触发比例（默认 90%） |
| 记忆 | 查看和编辑 Agent 的长期记忆（MEMORY.md）和用户资料（USER.md）。保存会直接覆盖文件内容。如果 Agent 配置里关闭了用户资料，该项显示只读 |
| 人格配置 | 编辑 AGENTS.md，写下希望 Agent 长期遵守的规则和背景，有字节数上限 |
| 学习状态 | 只读，显示 Agent 后台复盘的待处理数量，以及最近一次复盘和成功时间 |

外观是整个 xLyra 共用的设置，换了之后所有管理员看到的 `/agent` 背景都会一起变化。其他标签的内容保存在 Runner 的数据目录里。

如果某个标签提示「Runner 未连接或版本过旧」，先到 [设置页](./settings.md) 检查状态，再看是否需要升级 Agent。
