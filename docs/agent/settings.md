# Agent 设置页（/settings/agent）

在 xLyra 后台进入 **设置 → Agent 设置**。这个页面只有管理员能看到，负责三件事：连接 Runner、限定 Agent 能用的站点和模型、升级 Agent。

## 状态

页面顶部有两个状态灯和一个刷新按钮：

| 状态灯 | 含义 |
| --- | --- |
| Runner | xLyra 能不能连上 Runner 容器 |
| Agent | Runner 里的 Agent 是否在正常运行 |

状态含义：**正常**、**异常**（连得上但自身报错）、**不可达**（连不上）、**未知**（还没取到状态）。点「刷新状态」会立刻重新检查，页面也每 30 秒自动检查一次。

下方两张卡片分别显示 Runner 和 Agent 的当前版本。

## Runner 连接

| 项目 | 怎么填 |
| --- | --- |
| Runner 地址 | 例如 `http://xlyra-agent-runner:3211`。必须是 `http://` 或 `https://` 开头，不能带账号密码。末尾的 `/` 会自动去掉 |
| Runner Token | 填 Runner 容器里 `RUNNER_INTERNAL_TOKEN` 的同一个值 |

点「保存」生效，无需重启。

- Token 保存之后不会再显示出来，页面只提示「已配置」。留空保存表示保持原值，输入新值才会替换。
- 地址和 Token 要一起配好才能用。只填地址、不填 Token，或者 Token 与 Runner 不一致，状态灯会一直是「未知」，对话也发不出去。
- 「清空配置」会同时删除地址和 Token，`/agent` 入口随之消失，直到重新配置。

**也可以用环境变量预置**：xLyra 容器里设置 `AGENT_RUNNER_BASE_URL` 和 `AGENT_RUNNER_INTERNAL_TOKEN`，首次启动就带上这两项。页面上保存过的值优先于环境变量，所以以后请以页面为准。清空配置在重启后，环境变量里的值会重新生效。

## 站点与模型范围

默认 Agent 能用 xLyra 里所有启用的站点和模型。想限制时点「配置范围」：

| 选项 | 效果 |
| --- | --- |
| 站点范围：全部站点 / 仅指定站点 | 选「仅指定站点」后，只有勾选的站点可用 |
| 模型范围：全部模型 / 仅指定模型 | 选「仅指定模型」后，只有勾选的模型可用。选了「仅指定站点」时，模型范围会在这些站点里选 |

点「保存」后立刻生效，不需要重启 Runner。旁边「可用站点」「可用模型」两张卡片可以点开查看当前实际生效的列表，并支持搜索。

这个范围只影响 Agent。xLyra 其他的 API 密钥、路由不受影响。

## 升级 Agent

当 Runner 的 `AGENT_MANAGED` 为 `true`（默认）时，Agent 卡片上会显示当前版本。有新版本时出现「可升级 x.y.z」的标记和「升级」按钮。

1. 点「升级」，确认。
2. 页面进入「升级中」，约几分钟，期间 Agent 会重启。
3. 完成后提示「Agent 已升级到 x.y.z」。失败时提示失败原因，并出现「重试升级」。

如果当时还有对话正在运行，会先提示「有会话正在运行」。继续升级会中断这些对话，请确认没有重要任务再点「强制升级」。

打开这个页面时会自动检查一次新版本，Runner 会把结果缓存一小时。

`AGENT_MANAGED=false` 时没有升级按钮，Agent 版本显示「自管理」。
